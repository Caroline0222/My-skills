# 信息盘点 + 追问清单

## 原则

**信息不全不脑补**。一次追问不超过 1 轮，每轮不超过 3 个问题。

---

## 必备 vs 可选字段

| 字段 | 类别 | 缺失后果 |
|---|---|---|
| 目标岗位 JD（完整文本） | 必备 | A/B/C/D/E 全部依赖 |
| 个人简历（最近 3 段 + 量化结果） | 必备 | B/C/D 全部依赖 |
| 公司名 / 行业 | 必备 | A 章节无法做 |
| 行业 / 职能 | 必备 | E 章节按需启用必须知道 |
| 面试轮次（HR / HM / Case / Panel / 终面） | 可选 | 没给时 E 章节全形式铺开 |
| 猎头 / HR 沟通记录 | 可选 | 有大用——常暗示面试重点 |
| 当前在职状态 | 可选 | 影响 B 章节语气 |
| 候选人**最想强调的 1-2 段经历** | 可选 | 让候选人主动暴露重点 |

---

## 标准追问顺序

### 第一轮：缺啥问啥（一次性给候选人）

| 候选人给的 | 追问 |
|---|---|
| 只有 JD | + 简历 + 公司 + 行业 / 职能 |
| 只有简历 | + JD + 公司 + 行业 / 职能 |
| 只有公司 / 行业 | + JD + 简历 + 行业 / 职能 |
| 都没有 | 礼貌说明本 skill 必须输入 JD + 简历 |

**范例**（一次性给候选人）：

> 为了更准地帮你定位，方便补充以下信息吗？
> 1. 目标岗位 JD 完整文本（岗位名 + 公司 + 关键要求）
> 2. 你最近一份简历（或 3 段核心经历 + 量化结果）
> 3. 你属于哪个职能 / 行业？

### 第二轮（仅当需要时）：深挖

- 猎头 / HR 提过这个岗位最看重什么吗？
- 你自己最想强调的 1-2 段经历？
- 简历里没写但你想让人知道的事？

> 第二轮**最多 1 次**。

---

## 行业 / 职能映射（决定 E 章节按需启用）

| 行业 / 职能 | E 章节启用重点 | 专业深挖维度 |
|---|---|---|
| 产品 | HM / Case / Behavioral / Take-home | 用户洞察、需求判断、优先级、指标、商业化、协作 |
| 运营 | HM / Behavioral / Situational | 流程、数据、机制、增长、成本、异常、规模化 |
| 销售 / 商务 | HM / Role Play / Case | 客户洞察、商机推进、异议、谈判、预测、复购 |
| 市场 | HM / Presentation / Take-home | 用户、品牌、内容、渠道、活动、预算、ROI |
| HR | HM / Behavioral / Situational | 招聘、绩效、组织、员工关系、人才发展、业务协同 |
| 财务 | HM / Professional / Case | 报表、预算、审计、税务、经营分析、内控 |
| 法务 | HM / Professional / Case | 风险识别、合同、合规、谈判、业务支持 |
| 设计 | HM / Portfolio / Case | 研究、信息架构、交互、视觉、可用性、业务影响 |
| 技术 / 数据 | HM / Professional / Take-home | 基础原理、系统、代码 / 数据、性能、可靠性、安全 |
| 项目 / 咨询 | HM / Case / Behavioral / Panel | 问题定义、范围、里程碑、风险、协作、交付、价值 |
| 管理岗 | Final Executive / Panel / Presentation | 战略、团队搭建、培养、艰难决策、组织变化 |

## 信息组织模板（内部用，**不直接给候选人**）

```
【岗位】
- 公司：
- 岗位名：
- 行业 / 职能：
- 面试轮次：

【JD 关键词】
- 角色定位：
- 关键能力 3-5 项：
- 隐性偏好：
- 加分项：

【简历关键素材】（按 8 字段挖矿）
- 经历 A：背景 / 问题 / 约束 / 判断 / 行动 / 证据 / 结果 / 复盘
- 经历 B：
- 经历 C：

【公司画像待调研】
- 业务定位：
- 近期动态：
- 行业 / 竞品：
- 面试前必知：

【定位主线】
- 用 1 句话概括本次面试你想让面试官记住什么：

【适配考核】
- 启用的面试形式（HR / HM / Case / Panel ...）：
  - 专业深挖方向（产品 / 运营 / 销售 / HR / 财务 / 技术 ...）：
```

任何一项缺位，就回去追问或标注"未提供"。

---

## 输出前的自检

- [ ] JD / 简历 / 公司三要素至少有其二
- [ ] 行业 / 职能已确定
- [ ] 缺失项已问过候选人，或在最终输出里**显式标注**（"此项为基于公开信息的合理推测"）
