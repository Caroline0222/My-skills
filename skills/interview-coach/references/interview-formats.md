# E｜适配 + 练习 — 10 种面试形式 + 最小练习包

## 目标

**全行业适用，但根据岗位按需启动**。由候选人岗位与轮次决定启用哪些形式。

---

## 一、10 种面试形式一览

| 面试形式 | 常见考察 | 准备重点 |
|---|---|---|
| **HR Screening** | 动机、经历、基本匹配 | B 章节定位 + 离职原因 |
| **Hiring Manager** | 业务价值、核心能力 | D 章节故事 + 入职 90 天思路 |
| **Behavioral** | 过去怎么做 | C/D 章节 8 字段故事 |
| **Situational** | 遇到情况怎么办 | 判断框架 + 优先级 + 沟通策略 |
| **Professional / Technical** | 专业深度 | 原理 + 工具 + 案例 + 边界 |
| **Case** | 分析、拆解、决策 | Case 8 步框架（下方） |
| **Presentation** | 表达、逻辑、高管沟通 | 内容架构 + 时间 + Q&A 数据口径 |
| **Portfolio Review** | 作品与个人贡献 | 过程 + 决策 + 反馈 + 复盘 |
| **Take-home Assignment** | 独立思考和完成质量 | 范围 + 结构 + 时间管理 |
| **Role Play** | 沟通、销售、谈判 | 提问 + 倾听 + 异议 + 推进 |
| **Panel** | 协作与多角色表达 | 同一案例从业务 / 协作 / 专业三层 |
| **Final / Executive** | 成熟度、判断、长期匹配 | 业务理解 + 战略 + 动机 |

## 三、Case 通用作答 8 步

| 步骤 | 做什么 |
|---|---|
| **1. 明确目标** | 要解决什么，谁定义成功？ |
| **2. 澄清现状** | 已有数据、资源、约束、利益相关方？ |
| **3. 提出假设** | 哪些是事实，哪些待验证？ |
| **4. 拆解问题** | 分成可分析的几块（MECE） |
| **5. 做优先级** | 先做什么、后做什么、不做什么？ |
| **6. 给出方案** | 行动、负责人、节奏、风险控制 |
| **7. 定义验证** | 指标、里程碑、反馈机制 |
| **8. 总结结论** | 用 30 秒回到问题本身 |

### 反例 vs 正例

| 反例 | 正例 |
|---|---|
| 一上来就给方案 | 先问"目标 / 约束 / 假设" |
| 用大词（"打造""赋能"） | 用具体动作（"前 2 周做 X，第 3 周做 Y"） |
| 不说假设 | 明确说"假设 A 是事实、B 待验证" |
| 不做优先级 | 明确说"先做 X（影响最大），后做 Y（影响小）" |
| 不给验证 | 明确说"用指标 Z 验证，3 周后看数据" |

### Case 准备方法

1. 准备 **3-5 个通用 Case 题型**答案：
   - 增长类（如何把 DAU 拉 30%）
   - 效率类（如何把流程压到 1 天）
   - 客户类（如何挽回流失客户）
   - 团队类（如何带 5 人小组完成 0→1）
   - 战略类（如何判断是否进入新市场）
2. 每个 Case 都按 8 步框架练 2-3 遍
3. 练到能 5 分钟内给出完整框架

## 四、最小练习包

### 必备 8 项

1. **30 秒定位**（B 章节第 1 段）
2. **1 分钟自我介绍**（B 章节衍生）
3. **2 个核心经历故事**：各准备 1 / 2 / 5 分钟版
4. **1 个失败 / 挑战故事**（含复盘）
5. **1 个冲突 / 协作故事**
6. **1 个职业转换或离职原因**（D 章节履历防守卡）
7. **1 个岗位相关的专业深挖题**（D 章节第 3 类）
8. **1 个情境题**（Situational）

### 按需 5 项

- 1 个 Case（按 8 步框架）
- 1 个 Presentation / Portfolio / Role Play
- 3 个反问（见下方）
- 每个核心故事至少被连续追问 3 层
- 录音回放 ≥ 1 次（修改 3 处"不像自己"的地方）

### 反问题库（按轮次选 3 个）

| 反问类型 | 范例 |
|---|---|
| **业务方向** | 未来 6 个月最重要的 1 件事是什么？ |
| **团队现状** | 这个岗位补位团队的核心痛点是？ |
| **面试官视角** | 您希望候选人 3 个月后达成什么？ |
| **个人发展** | 晋升路径 / 培养机制？ |
| **文化** | 团队最引以为豪的一件事？ |
| **招聘节奏** | 若通过，下一轮安排在什么时候？ |

## 五、练习通过标准

| 练习项 | 通过标准 |
|---|---|
| 自我介绍 | 60 秒内完成，有定位，不是简历复读 |
| 经历故事 | 可切换长短版本，事实始终一致 |
| 数字和成果 | 能解释来源、口径、范围、个人贡献 |
| 离职原因 | 正向、简洁、不抱怨、不自相矛盾 |
| 专业题 | 能说明是什么、为什么、怎么做、风险与边界 |
| 情境题 | 有判断框架，有优先级，不空喊"先沟通" |
| Case | 先澄清、再假设、再分析、有结论 |
| 追问 | 三层追问后仍不夸大、不模糊、不跑题 |
| 反问 | 与岗位、轮次、面试官角色有关 |

## 六、面试当天临场调整

### 节奏

| 现象 | 调整 |
|---|---|
| 时间不够（剩 1 分钟） | 切到 1 分钟版本 |
| 时间多了（剩 5 分钟） | 切到 5 分钟版本 + 主动暴露细节 |
| 被打断 | "请允许我用 30 秒讲完这个结论" |

### 情绪

| 现象 | 调整 |
|---|---|
| 被问到不会的 | "这块我没有直接经验，但从 XX 角度切入，可以谈谈我的理解" |
| 被连续追问 3 层 | 不急，按"事实 → 判断 → 复盘"逐层答 |
| 面试官很冷 | 主动问 1 个反问，拉回对话节奏 |

### 内容

| 现象 | 调整 |
|---|---|
| 数字被质疑 | 解释口径 + 范围 + 个人贡献 |
| 故事讲乱了 | "我先讲结论，再补背景" |
| 跑题了 | 主动拉回"我想补充一句，回到 XX" |
