# A｜了解机会 — 公司画像研究

## 目标

让候选人在 5 分钟内能自信地聊这家公司的**业务、阶段、与岗位相关的变化**——不追求百科全面，只追求"与岗位有关"。

---

## 一、必输出 vs 按需输出

### 必输出（A 章节机会卡核心字段）

| 字段 | 用途 |
|---|---|
| **公司一句话** | 它为谁提供什么价值 |
| **与岗位相关的业务 / 产品 / 客户群** | 决定候选人要不要懂某个细分 |
| **近 6–12 个月与岗位有关的关键变化** | 解释为什么有这个岗位 |
| **该岗位可能要解决的核心问题** | A + B 章节的衔接 |
| **面试前必知 3 件事** | 公开信息、可被直接问 |

### 降级为按需项（不写就 OK）

- 行业地位、完整竞品、所有产品线、精确日期、大量融资 / 奖项 / 品牌新闻

---

## 二、信息源（按可信度）

| 来源 | 用途 | 工具 |
|---|---|---|
| 公司官网（about / 产品 / 团队） | 业务定位、产品矩阵 | WebFetch / agent-browser |
| 招聘官网 JD 信息 | 团队在做的事、组织阶段 | 同上 |
| 36Kr / 虎嗅 / 极客公园 | 近期动态、融资、产品发布 | WebSearch |
| 创始人 / CEO 公开访谈 / 微博 | 公司价值观、阶段 | WebSearch |
| LinkedIn / 脉脉 / 看准 | 面试官公开主页 | WebFetch |

> 调用顺序：WebSearch 找最新动态 → WebFetch 拉详细页面。

---

## 三、机会卡画布

### 1. 一句话业务定位

> 用 1 句话说清公司做什么、给谁用、解决了什么。
>
> 示例：美团——本地生活服务平台，把餐饮外卖、到店、酒旅聚合到 1 个 App。

### 2. 与岗位相关的业务 / 产品 / 客户群

> **只写与候选人面试岗位有关的部分**，不写全部产品线。

| 维度 | 内容 |
|---|---|
| 业务定位 | 占 70%+ 收入来源的主业务 |
| 增长业务 | 高增速但占比小 |
| 客户群 | 主要客户类型 / 行业 / 规模 |

### 3. 近 6–12 个月关键变化（**只写与岗位有关**）

每条变化包含：**时间 + 事件 + 对岗位的潜在影响**。

> 示例：2025-08 完成 D 轮 2 亿美元融资 → 可能意味着团队扩张 / 新业务线启动 → 候选人面试的岗位大概率是新业务线相关。

### 4. 该岗位可能要解决的核心问题

把 JD 核心目标 + 公司近期变化 → 推导出"为什么这个岗位现在存在"。

### 5. 面试前必知 3 件事

> 这是候选人**至少要记住**的、可能直接被问的事实。

### 6. 面试前最后刷新

提醒候选人，面试前 1 小时**再快速看一次**：

- 公司新闻（最近 2 周）
- JD（有时 HR 会微调）
- 面试通知里提到的面试官名字（搜其公开主页）

---

## 四、没拿到公司名时的处理

如果候选人只给了行业（如"金融科技 SaaS"），按下面骨架生成"**行业级机会卡**"：

- **赛道**：XX 行业 SaaS
- **典型玩家**：A、B、C
- **行业阶段**：增长期 / 出清期 / 红利期
- **普遍痛点**：合规、客户教育成本、销售周期长

并在卡片末尾明确写：

> ⚠️ 此卡片基于公开行业信息，**建议补充具体公司名**以做针对性研究。

## 五、写作原则

| 原则 | 怎么做 |
|---|---|
| **与岗位有关优先** | 所有字段都过一遍"这个跟候选人面试的岗位有什么关系" |
| 事实优先 | 每个论断标信源（如"据 36Kr 2024-12 报道"） |
| 拒绝"业内领先""技术先进"等空词 | 用事实替代（"市占率 Top 3""融资额 1 亿美元"） |
| 不预测 | "我们预计下半年 …"→ 不写 |
| 时间敏感 | 标注信息发布时间 |

## 六、接入外部 Connector（可选）

如果用户启用了 connector（如天眼查 / 企查查 / 启信宝 / PitchBook 等），A 章节**可叠加工商硬数据**：

| 数据维度 | 推荐 Connector |
|---|---|
| 实控人 / 股东穿透 / 控股结构 | 天眼查（tyc-mcp） |
| 对外投资 / 子公司布局 | 天眼查 / 启信慧眼 |
| 法律诉讼 / 风险扫描 | 天眼查 |
| 工商变更（融资、重组、上市） | 天眼查 / 企查查 |
| 海外公司信息 | PitchBook / MergerInfo / dnb-global-data |

**用法**：
1. 用户在 WorkBuddy 连接器面板启用目标 connector
2. AI Agent 直接调对应 MCP 工具获取数据
3. 没启用时退化为 WebSearch / WebFetch 抓公开信息

## 七、输出格式

A 章节最终交付字段：

```
A1. 业务定位（公司一句话）
A2. 与岗位相关的业务 / 产品 / 客户群
A3. 近 6–12 个月关键变化（与岗位有关）
A4. 该岗位可能要解决的核心问题
A5. 面试前必知 3 件事
A6. 面试前最后刷新（提醒）
A7. 信源备注
```
