# 选型方案输出模板 — 8 大块表结构

## 使用说明

- **本文件只定义结构，不含内容**。按客户需求逐块填，缺信息留「需客户确认」，不留空。
- **列名不可增删**，行数按实际情况增补。表结构稳定才能跨项目复用。
- **每个结论后标约束编号**（如 `[C3][C7]`），指向块 1 的行号，让客户能反查依据。
- HTML 版以本文件为准，`assets/selection-report-template.html` 只是可选美化产物。
- 项目一律用**脱敏行业代号**（如"某体育场馆票务服务""某警务知识问答"），不出现客户实名、不出现报价金额。

## 块 6｜每个成功任务成本测算

### 6a 单任务口径

| 方案 | 计费口径 | 输入 token/任务 | 输出 token/任务 | 放大系数 R | 成功率 S | 每成功任务成本 | 单价（占位·待填） | 单价来源 |
|---|---|---|---|---|---|---|---|---|
| | API 按 token / 自建按 GPU 小时 / 混合 | | | | | | 待填 | 官网 / 客户报价 / 需确认 |

> **R 与 S 必填，不填视为测算无效。** R含重试与工具调用放大，S 为实际成功率（不是标称）。漏算这两项会系统性低估 API 方案成本。

### 6b 年度与三年

| 方案 | 年请求量 | 年成功任务数 | 年成本 | 折算 GPU 小时 | 三年 TCO（保守） | 三年 TCO（中性） | 三年 TCO（乐观） |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

### 6c GPU ↔ Token 等效换算（自建 vs API 必填）

| GPU 方案 | 卡数 / 型号 | 单卡小时成本 | 年 GPU 小时 | 年 token 量 | 等效单价 P_equiv | 对比 API 单价 | 盈亏平衡请求量 Q* |
|---|---|---|---|---|---|---|---|
| | | 待填 | | | 待填 | | |

> Q* = 自建年固定成本 ÷（API 单价 − 自建等效单价）。**Q* 小于客户年请求量 → 自建更省**，反之调API。
