# C｜证据 + 故事 — 4 列矩阵 + 8 字段故事

## 目标

把 JD 每条要求 → 配上候选人的**真实证据** → 落到 6 类故事上。**不写 ⭐⭐⭐ 主观评分**——用证据等级（🟢🟡🔴）。

---

## 一、4 列证据矩阵（精简版）

| 列 | 含义 |
|---|---|
| **JD 要求** | JD 第 3 层拆出来的 Must-have 能力（动词+名词） |
| **我的证据** | 候选人的 1 段经历（用 8 字段简写） |
| **等级** | 🟢 直接 / 🟡 可迁移 / 🔴 待补 |
| **可能追问** | 1-2 个高风险问题 |

### 证据等级

| 等级 | 含义 | 适用 |
|---|---|---|
| 🟢 **直接证据** | 有真实经历、具体动作、可解释结果 | 候选人做过类似的事，能讲清楚来龙去脉 |
| 🟡 **可迁移证据** | 领域不同，但问题与能力结构相似 | 候选人没做过这个行业，但别的行业干过类似的事 |
| 🔴 **待补足项** | 没有直接证明，需准备应对策略 | 候选人完全没接触过 |

> 至少 60% 应该是 🟢 / 🟡。不可全部都是 🔴。

### 矩阵输出格式

```
| JD 要求 | 我的证据 | 等级 | 可能追问 |
|---------|---------|------|---------|
| **0→1 增长** | DAU 80万→118万；7日留存 18%→26% | 🟢 直接 | 谁反对？怎么改变？ |
| **跨部门协作** | 建过 4 部门联动增长小组 | 🟢 直接 | 结果由你直接造成？ |
| **AI Agent 经验** | ⚠️ 没直接经验。应对：增长视角切入 | 🔴 待补 | 怎么快速上手？ |
```

## 二、8 字段故事（替代 STAR）

STAR 升级为 8 字段，因为缺**约束 / 判断 / 复盘**：

| 字段 | 含义 |
|---|---|
| **背景** | 场景、业务目标、相关角色 |
| **问题** | 到底要解决什么（不是任务，是问题） |
| **约束** | 时间 / 预算 / 资源 / 合规 / 能力边界 |
| **判断** | 你为什么选这个方向，不选另一个 |
| **行动** | 你本人做了什么（按顺序） |
| **证据** | 数据、反馈、交付物、变化、验证方式 |
| **结果** | 结果是什么 + 个人贡献占比 |
| **复盘** | 如果重做，会调整什么 |

### 8 字段范例

**反面**（简历原文）：

> 负责 XX 业务的产品迭代，与运营团队协作完成拉新目标。

**8 字段后**：

> **背景**：2023 年 XX 业务月活停滞，连续 3 个季度增长 < 2%。
> **问题**：把 DAU 从 80 万提升到 120 万。
> **约束**：3 个月时间窗口、团队只有 1 个 PD、不能影响付费用户留存。
> **判断**：选"留存重构 + 召回体系"两条腿走路，不选纯拉新（留存比 CAC 杠杆高）。
> **行动**：1）主导留存模块重构，新手引导从 7 步砍到 3 步；2）与运营共建 RFM 召回体系；3）建 AB 测试节奏。
> **证据**：新用户 7 日留存 18%→**26%**；DAU 3 个月 80 万→**118 万**。
> **结果**：DAU 达成目标的 95%，个人贡献占增长盘子的 60%。
> **复盘**：会更早启动召回体系（晚了 4 周），且留存口径没锁稳导致中间 2 次反复。

## 三、6 类故事（必背至少 4 类）

| 故事类别 | 面试常考能力 | 长度建议 |
|---|---|---|
| **代表性成果** | 价值创造、专业能力 | 5 / 2 / 1 分钟版 |
| **最难的问题 / 挑战** | 抗压、问题解决 | 5 分钟版 |
| **冲突或分歧** | 沟通、影响力、协作 | 3 分钟版 |
| **失败或判断失误** | 复盘、成长性、责任感 | 3 / 1 分钟版 |
| **主动推动的改进** | Owner 意识、创新、执行力 | 3 分钟版 |
| **快速学习 / 跨界转型** | 适应力、学习能力 | 2 分钟版 |

**管理岗追加**：带人培养、艰难决策、资源争取与优先级取舍、组织变化与战略落地。

### 故事之间的对应关系

| 故事类别 | 对应证据等级 |
|---|---|
| 代表性成果 | 🟢 直接证据中的"代表经历" |
| 失败 / 复盘 | 🟢 / 🟡 中"个人贡献"边界 |
| 冲突 / 协作 | 🟢 "跨团队"证据 |
| 主动改进 | 🟢 "Owner 意识"证据 |
| 快速学习 | 🟡 可迁移证据 |

---

## 四、矩阵 → 故事的衔接

```
矩阵的每条 🟢 直接证据 → 进入 D 章节的"故事深挖"
矩阵的每条 🔴 待补 → 进入 D 章节的"履历防守卡高风险问题"
```

每段经历、每个故事都要写满 8 字段，**不能只写 4 字段（STAR）就结束**。
