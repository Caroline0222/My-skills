# Anti-AI Style — 去 AI 味的替换词典

## 核心原则

面试素材**要让候选人能用嘴讲出来**，所以必须像候选人**自己**说的话，不是 LLM 写出来的报告。

面试候选人在面试中"像不像自己"，比"听起来多专业"更重要。

---

## 面试场景的硬规则（B 章节定位四件套专属）

B 章节 4 段定位（30 秒 / 1 分钟 / Why me / Why this role）是最容易翻车的地方——因为这是候选人会**真的念出来**的话。

### 硬规则

| 规则 | 怎么做 |
|---|---|
| **不要从"我做过什么岗位"开始** | 从"我擅长解决什么类型的问题"开始 |
| 每段必须有 1 个数字 | 没数字候选人自己都说服不了自己 |
| 念出声能 60 秒念完 | 4 段加起来不超过 240 秒 |
| **不要用形容词堆砌** | "优秀 / 出色 / 卓越"删掉，改为"做了什么" |
| **避免"基于""围绕""通过"等虚词开头** | 改为主语直接动作 |

### 错误 vs 正确示例

| 错误 | 正确 |
|---|---|
| 我是一名**优秀的产品经理**，在过去的 6 年里**深入贯彻**了用户增长理念 | I 是产品经理，过去 6 年专注在 SaaS 和工具类产品的用户增长 |
| 我**打造了**完整的增长**闭环** | 我主导留存重构，把 7 日留存从 18% 拉到 26% |
| 我**赋能**了跨部门协作 | 我推动过 4 部门联动的增长项目 |

## 高频问题词与替换

### 1. 互联网黑话 / PPT 词汇

| AI 味词 | 替换 |
|---|---|
| 赋能 | 帮 XX / 让 XX |
| 抓手 | 切入点 / 突破口 |
| 闭环 | 把 XX 到 XX 全流程打通 |
| 沉淀 | 整理 / 留下可复用方法 |
| 打造 | 做 / 做了 XX |
| 体系化 | 系统地做 / 按框架做 |
| 数字化转型 | 把流程放到线上 / 用数据代替人工 |
| 全链路 | 从 XX 到 XX 都参与 |
| 商业化 | 收钱 / 跑通付费模型 |
| 拉通 | 拉齐 / 让 XX 同步 |
| 颗粒度 | 细到多少 / 拆分维度 |
| 打法 | 思路 / 方法 |
| 底层逻辑 | 思路 / 原理 |
| 顶层设计 | 全局规划 / 整体方案 |
| 衍生 | 引出 / 顺带做 |

> 面试官听到"赋能""抓手""闭环"**会扣分**——候选人用了，就知道是 AI 写的。

### 2. 形容词堆砌

| AI 味 | 替换 |
|---|---|
| 显著提升 | 写出数字（如 +30%） |
| 大幅增长 | 写出数字 |
| 卓越 / 杰出 / 出色 | 删除，改为"做了什么" |
| 优秀的 XX | 写出"优秀的具体行为"（如"主动承担了 XX 责任"） |
| 全面 / 系统性 | 拆成具体动作 |

### 3. 浮夸动词

| AI 味 | 替换 |
|---|---|
| 深入贯彻 | 做 |
| 大力推进 | 推动 |
| 攻克 / 突破 | 解决 |
| 攻坚克难 | 解决问题 |
| 提质增效 | 提效率 |

### 4. 时间描述

| AI 味 | 替换 |
|---|---|
| 在 XX 期间 | 2023.06 - 2024.03 |
| 近年来 | 写出年份范围 |
| 长期 | 写出几个月 / 几年 |
| 持续 | 写出做了多少次 / 多长周期 |

### 5. 抽象表述 → 具体行为

| AI 味 | 替换（举例） |
|---|---|
| 推动业务增长 | 让月活从 80 万 → 118 万 |
| 加强团队建设 | 每周开 1 次 1-on-1，建了新人 onboarding 文档 |
| 提升用户体验 | 把新手流程从 7 步砍到 3 步 |
| 优化流程 | 把 XX 流程从 5 天压到 2 天 |

## 替换口径

### 数字优先
任何模糊评价**都能用数字 / 范围 / 频次替代**。没有数字就说"做得多频繁"。

### 时间具体化
**所有时间段描述都要带具体日期/月份**。"近期""过去几年"删除。

### 主体具体化
**避免"我们"开头**。改成"我"——面试素材本身就是个人陈述。

| AI 味 | 替换 |
|---|---|
| 我们完成了 XX | 我完成了 XX |
| 团队实现了 XX | 我和团队一起把 XX 做了 |
| 公司启动 XX 项目 | 我在 XX 期间主导了 XX |

## 自检流程（生成完所有卡片后）

逐卡过：

1. **搜词扫描**：
   - 搜 "赋能 / 抓手 / 闭环 / 沉淀 / 打造 / 体系化 / 全链路 / 颗粒度 / 底层逻辑"
   - 任一命中 → 替换

2. **主体检查**：
   - 看每条 STAR-R 主语是不是"我"
   - 不是 → 改

3. **数字检查**：
   - 每个 R（结果）必须含数字、百分比或具体范围
   - 没数字 → 候选人确认或删除

4. **口语化检查**：
   - 把每段第一句念出声
   - 像不像候选人会**真的这么讲**？
   - 不像 → 重写

---

## 兜底：让候选人自检风格

生成完卡片后，**显式建议**：

> 请用你自己的话把"卡 4 一句话定位"重新念一遍。如果你念的时候觉得哪里"不像自己"，告诉我，我重写。

这个反馈循环比任何技术都管用。
