# D｜准备 + 深挖 — 履历防守 + 三级追问 + 专业深挖

## 目标

面试官追问的三类问题，都准备好：

1. **简历深挖**（每段经历）—— 履历防守卡
2. **故事深挖**（每个核心故事）—— 三级追问
3. **专业深挖**（按岗位）—— 不预设技术

---

## 一、履历防守卡（每段经历）

每个候选人 **每段简历经历**准备一张卡，覆盖 7 个字段：

| 字段 | 准备内容 |
|---|---|
| **公司与岗位背景** | 公司类型 / 业务 / 团队 / 职责边界 |
| **我为什么加入** | 当时的选择逻辑（真实、正向） |
| **我负责什么** | 3 条以内、可验证 |
| **最大成果** | 1-2 项，写清个人贡献 |
| **为什么离开 / 转换** | 正向、真实、一致 |
| **与新岗位的连接** | 我带得走的能力 |
| **高风险问题** | 容易被质疑的职责 / 数字 / 头衔 / 空窗期 / 频繁跳槽 |

### 必带问题清单

面试官沿简历时间线可能问：

1. 为什么加入这家公司？
2. 为什么离开？
3. 为什么转行 / 转岗 / 转城市？
4. 你的职位名称和实际职责分别是什么？
5. 汇报给谁？团队多大？你管理多少人？
6. 哪些工作是你独立完成，哪些是团队成果？
7. 这个项目 / 客户 / 工作最后结果怎样？
8. 为什么你现在要找新机会？

### 高风险问题特别注意事项

| 高风险类别 | 应对要点 |
|---|---|
| **空窗期** | 主动解释（进修 / 照顾家庭 / 主动选择），不回避 |
| **频繁跳槽** | 给一个统一逻辑（行业阶段 / 个人阶段 / 业务调整） |
| **title 与实际不匹配** | 用"实际负责"澄清，避免被质疑 |
| **数字跳变** | 提前解释口径（如：并购贡献 / 业务转型） |
| **从大厂到小厂（或反向）** | 给出"为什么这个选择对我个人更合理"的逻辑 |
| **跨城市 / 跨国家** | 解释长期规划（家人 / 行业聚集度） |

### 离职原因 / 职业转换表达口径

| 离职原因类型 | 表达口径 |
|---|---|
| 业务调整 / 裁撤 | "公司在 X 月完成组织调整，我负责的 Y 业务线关停" |
| 发展受限 | "晋升通道在 2 年内没打开，结合我的目标，看外面机会" |
| 业务转型 | "公司从 X 转型到 Y，我个人更想在 X 方向深耕" |
| 团队 / 文化 | "团队在 X 月后调整方向，与我个人发展预期不一致" |

> **原则**：正向、真实、一致；不抱怨、不自相矛盾。

## 二、故事三级追问（每个核心故事）

每个核心故事至少做**三级追问准备**：

| 层级 | 面试官在确认什么 | 我的应对模板 |
|---|---|---|
| **第一层：事实** | 是否真实、你参与到哪里 | "这事 2023 年 Q3 在 XX 公司做的，我负责 [角色]。结果是 [数字]。" |
| **第二层：判断** | 是否真正做过决策 | "选这个方向是因为 [理由]。我考虑过 [替代方案]，但 [风险]，所以放弃。" |
| **第三层：复盘** | 是否具备成熟度 | "事后复盘，我会在 [时机] 更早启动 [动作]。原因是 [当时的约束 / 现在的认知]。" |

> **关键**：第三层答不上 = 面试官觉得"这人没反思"。**每个故事必须把复盘字段写好。**

### 三级追问的常见漏点

| 漏点 | 后果 |
|---|---|
| 第一层讲不清事实 | 面试官怀疑经历真实度 |
| 第二层说"我老板让我这么做的" | 显得没判断力 |
| 第三层说"没什么可调整的" | 显得没反思 |
| 三级之间数字不一致 | 立刻被质疑 |

## 三、专业能力深挖（按岗位按需启用）

**不预设技术**，按岗位类型启用：

| 角色类型 | 可能深挖方向 |
|---|---|
| 产品 | 用户洞察、需求判断、优先级、指标、商业化、协作 |
| 运营 | 流程、数据、机制、增长、成本、异常、规模化 |
| 销售 / 商务 | 客户洞察、商机推进、异议、谈判、预测、复购 |
| 市场 | 用户、品牌、内容、渠道、活动、预算、ROI |
| HR | 招聘、绩效、组织、员工关系、人才发展、业务协同 |
| 财务 | 报表、预算、审计、税务、经营分析、内控 |
| 法务 | 风险识别、合同、合规、谈判、业务支持 |
| 设计 | 研究、信息架构、交互、视觉、可用性、业务影响 |
| 技术 / 数据 | 基础原理、系统、代码 / 数据、性能、可靠性、安全 |
| 项目 / 咨询 | 问题定义、范围、里程碑、风险、协作、交付、价值 |

### 准备方法

按候选人岗位类型**勾选上表对应行**，每行准备 **3-5 个深挖题**：

**范例：产品岗深挖题**

1. 你最近一个产品需求是怎么从用户洞察变成上线的？
2. 你怎么判断需求的优先级？用过什么框架？
3. 如果给你一个数据不好的功能，你怎么决定是优化还是下线？
4. 你和研发撕过最激烈的一次是什么？怎么收场的？
5. 你的指标体系是怎么搭的？怎么衡量"成功"？

> 每题准备 1-2 分钟的答案，必须含数字、判断、复盘。

---

## 四、三类深挖的衔接

```
简历深挖（履历防守卡）
      ↓ 选段进入 ↓
经历 / 项目深挖（三级追问）
      ↓ 选段进入 ↓
专业能力深挖（按岗位）
```

> 三类深挖**互补不重叠**：
> - 履历防守卡 = 解决"你简历整体可信吗"
> - 三级追问 = 解决"你做的这个事你真懂吗"
> - 专业深挖 = 解决"你专业能力到哪一层"

## 自检

- [ ] 每段简历经历都有防守卡
- [ ] 每个核心故事做三级追问（特别是第三层复盘）
- [ ] 专业深挖题 ≥ 3 个，按岗位类型准备
- [ ] 高风险问题已识别 + 应对准备
- [ ] 三类深挖不重叠，覆盖所有可能追问
