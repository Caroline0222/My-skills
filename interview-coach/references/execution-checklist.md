## 面中（实时）

### 听题与判断

| 问题类型 | 特征 | 应对 |
|---|---|---|
| **事实** | "你做了什么 / 结果是什么" | 8 字段故事，直接给数字 |
| **行为** | "讲一个过去 XX 的例子" | STAR / 8 字段，重点在"我做了什么" |
| **情境** | "如果你遇到 XX 你怎么办" | 8 步 Case 框架：澄清 → 假设 → 分析 → 结论 |
| **专业** | "XX 工具怎么用 / 原理是什么" | 是什么 + 为什么 + 怎么做 + 风险 |
| **案例** | "现在给你一个问题 …" | Case 8 步框架 |
| **动机** | "为什么看机会 / 为什么选我们" | B 章节 Why this role |

### 表达节奏

- [ ] **先说结论，再补充背景** —— 不要先讲 5 分钟铺垫
- [ ] **明确区分**：你做了什么 / 团队做了什么 / 结果如何产生
- [ ] **不确定时说清假设和待确认点**，不硬答
- [ ] **面对连续追问**：先回到问题，再补细节，不急于夸大
- [ ] **Case 先澄清**，不直接给方案

### 数据与口径

- [ ] 数字必带口径（时间范围、对比基准、个人贡献占比）
- [ ] 数字被质疑时不慌，解释口径
- [ ] 不确定时主动说"这个数字我没具体记过，但从行业看是 XX 量级"

### 沟通与姿态

- [ ] 听清问题再答（必要时复述确认）
- [ ] 不要打断面试官
- [ ] 不要和面试官争论
- [ ] 适当用具体例子而非抽象表述
- [ ] 主动暴露短板 + 应对策略（不藏）

### 反问环节

- [ ] 每轮都准备 3 个反问（按 G 章节反问题库）
- [ ] 反问要有深度（不要问"贵司做什么"这种查得到的）
- [ ] 最后用反问**确认岗位成功标准**（"3 个月后您希望我达成什么"）

### 收尾

- [ ] 表达感谢（"感谢您的时间"）
- [ ] 询问下一步节奏（"如果通过，下一轮大概什么时候"）
- [ ] 不要当场谈薪资（除非对方主动问）

## 面后（T+0 到 T+24h）

> 本节为可选项，候选人是否做面后复盘看个人节奏。

### T+0：当场记录（5 分钟内）

> **趁热记忆**，写下来关键点：

- [ ] 问了哪些问题（记下原文）
- [ ] 我答得不好的 1-2 处（哪里超时 / 哪里被追问 / 哪里跑题）
- [ ] 面试官透露的关键信息（团队痛点 / 业务方向 / 文化）
- [ ] 面试官的肢体语言（冷淡 / 热情 / 严肃）

### T+24h：复盘（可选）

- [ ] 整体表现评分（1-5 分）
- [ ] 哪 1 段最该改：写下来、想清楚
- [ ] 哪 1 段最好：复用
- [ ] 下次面试要调整什么
- [ ] 是否继续跟进（与 HR / 猎头沟通）
